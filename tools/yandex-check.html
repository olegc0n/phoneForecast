Yandex Weather check

Does the key work, and what does the API say right now?

Why the address bar cannot do this. The key travels as an X-Yandex-Weather-Key header, and typing a URL cannot send a header. Opening the API URL directly returns 403 whether your key is good or bad.

And why a browser may still not settle it. A page loaded from a file has no origin the API will accept, so the browser may refuse to show the answer even when the server replied. That shows up below as blocked by the browser — inconclusive, not a failure of the key. Test 1 still tells you whether the phone can reach Yandex at all, and test 3 tells you whether the key works when passed a way the browser permits.
